Pocket Bird Guide to the Moscow Region

CourseworkAndroidJava
Code on GitHub

About the project

A mobile field guide for identifying birds of the Moscow Region, with social features. Users can browse profiles of 20 bird species with photo galleries and calls, record their own geotagged sightings on a map, and publish them to a shared community feed.

Technologies

Java, Android SDK (minSdk 29), Firebase Authentication, Cloud Firestore, OSMDroid (OpenStreetMap), ViewPager2, RecyclerView.

What's implemented

  • An offline guide based on local JSON with a custom parser
  • A photo carousel with a synced thumbnail strip
  • Email/password authentication with separate roles (user / administrator)
  • Creating sightings with bird name autocomplete and an interactive map
  • A feed of published community sightings
  • An admin panel for moderating posts

What I learned

  • Designing a client-server architecture following the MVC pattern
  • Working with a NoSQL database (Firestore): composite indexes, security rules, role-based access control
  • Building RecyclerView adapters with the ViewHolder pattern
  • Integrating third-party maps (OSMDroid) as an alternative to the Google Maps SDK
  • The full development cycle: from the technical specification and IDEF0/DFD diagrams to prototype testing
