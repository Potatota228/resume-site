Birds of Moscow and the Moscow Region

CourseworkWeb
Visit the site (in Russian) Code on GitHub

About the project

A multi-page educational website about the birds of Moscow and the Moscow Region. It includes a species guide with detailed profiles, a section of articles on how to help and observe birds, and a tongue-in-cheek quiz “Which Moscow-region bird are you?”. I built all the pages, layout and logic myself, without ready-made templates or libraries.

Features

  • A guide to 25+ species. Birds can be filtered by diet (predators, omnivores, granivores, insectivores) with a filter written in JS. There's also a statistics block.
  • A species profile for every bird: Latin name, taxonomy, conservation status, size, weight and wingspan, habitat, diet, breeding, voice and behavior, and a fun fact.
  • 12 articles: first aid for fledglings, rehabilitation of injured birds, winter feeding, migration, identifying birds by song, bird photography, the Red Book and other topics. Long articles have a sticky table of contents with anchor links.
  • An interactive 8-question quiz. It has a progress bar, lets you go back to the previous question, and the “Next” button stays disabled until an answer is chosen. The result is calculated by the number of matches and followed by a description of the bird, its personality traits and a link to its profile in the guide.
  • Responsive layout: on screens narrower than 800px a burger menu appears and the grids collapse into a single column.

Highlights

  • An animated hero illustration in pure CSS. The hills are made of rotated ellipses, and the tree has a hollow. When you hover over the banner, a bird peeks out of the hollow: it sits in a container with overflow: hidden, so only part of it is visible as it moves.
  • A burger menu without a single line of JS. It runs on a hidden checkbox and the :checked + label selector. The icon turns into a cross using ::before/::after, box-shadow and delayed transitions.
  • “Floating” birds in the quiz block. This is a CSS animation, @keyframes float, and each circle has its own animation-delay, so the birds bob out of sync.
  • Quiz data is separated from logic. Questions and results are stored in JS objects, and the interface is built from them dynamically. Adding a question or a new bird takes just one more entry.
  • A playful tone in the quiz: results like “Hostage of extroverts” or “Owl. They're not wise, they're grumpy cats with wings”. It makes the site livelier than a typical reference guide.

Technologies

HTML5, CSS3 (Flexbox, Grid, animations, media queries), vanilla JavaScript with no frameworks, Google Fonts, hosted on GitHub Pages.

What I learned

  • Building layouts without frameworks: Flexbox, Grid with auto-fit/minmax, positioning and z-index, handling overflow.
  • Making layouts responsive with media queries, and building interactive bits like a burger menu with CSS tricks instead of JS.
  • Working with the DOM in JavaScript: querying elements, toggling classes, creating elements dynamically, handling events.
  • Keeping UI state (current question, answers) and rendering screens from data instead of hard-coding them.
  • Maintaining a consistent visual style across 40+ pages: a shared palette and font, with common styles in a separate CSS file.
  • Designing information pages: convenient navigation through long texts and clearly structured profile cards.
  • Publishing a static site with GitHub Pages.
