# Сайт-резюме — как задеплоить на GitHub Pages

## Что нужно сделать перед публикацией

1. **Заменить плейсхолдеры.** Везде, где в html встречается текст вида
   `ЗАМЕНИТЬ-НА-ССЫЛКУ-НА-РЕПО` или `[Заполнить: ...]` — заменить на
   реальные ссылки и тексты. Проще всего искать по слову `ЗАМЕНИТЬ` и по `[`.
2. **Добавить скриншоты.** В карточках проектов сейчас стоят
   заглушки `<div class="placeholder-img">`. Когда появятся картинки —
   положи их, например, в `projects/img/`, и замени `div` на:
   ```html
   <img src="img/название.png" alt="Описание" style="width:100%; border-radius:14px; margin:20px 0;">
   ```
3. Проверить контакты на главной (email, GitHub, LinkedIn).

## Как опубликовать на GitHub Pages

1. Создай на GitHub новый репозиторий, например `polina-resume`
   (можно публичный).
2. В папке `resume-site` (эта папка целиком) выполни:
   ```bash
   cd resume-site
   git init
   git add .
   git commit -m "Первая версия сайта-резюме"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ-НИК/polina-resume.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Source** выбери ветку `main` и
   папку `/ (root)`, сохрани.
4. Через минуту-две сайт будет доступен по адресу вида:
   `https://ТВОЙ-НИК.github.io/polina-resume/`

Если хочешь, чтобы сайт был доступен по `https://ТВОЙ-НИК.github.io/`
(без имени репозитория) — назови репозиторий `ТВОЙ-НИК.github.io`.

## Структура проекта

```
resume-site/
├── index.html              — главная (резюме + готовые проекты)
├── projects.html           — галерея всех проектов с фильтрами по тегам
├── css/style.css           — общие стили
├── js/filter.js            — логика фильтрации по тегам на projects.html
└── projects/
    ├── birds-website.html
    ├── birds-android.html
    ├── cat-roguelite.html
    ├── dnd-dm-tool.html
    └── playtest-research-tool.html
```

## Как добавить новый проект

1. Скопируй любой файл из `projects/` как шаблон.
2. Заполни заголовок, статус (`done` / `progress`), теги, ссылки, текст.
3. Добавь карточку с таким же набором тегов (`data-tags="..."`) в
   `projects.html`, и если нужно — в `index.html` (если проект «готовый»).
4. Если используешь новый тег — добавь для него кнопку в `.filter-bar`
   на `projects.html` (`data-filter="Новый Тег"`).

## О двуязычности

Сейчас сайт полностью на русском (`lang="ru"`). Если позже понадобится
английская версия — самый простой вариант: сделать копию всех файлов
в папку `/en/` с переведённым текстом и добавить переключатель языка
в шапку (`nav`). Контент уже разложен по секциям с понятными
заголовками, так что переводить будет несложно.
